LG Valeting Admin Portal

Upload this ZIP to the separate Cloudflare Pages project for admin.lgvaleting.com.

Supabase setup:
1) Authentication > URL Configuration: add https://admin.lgvaleting.com/*
2) SQL Editor: run SUPABASE_ADMIN_FIX.sql if your account is not recognised as master/admin.
3) Login at https://admin.lgvaleting.com with your verified Supabase account.

If login works but dashboard says not admin, your profile row has not been promoted yet.
